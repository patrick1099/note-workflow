# Prior-art boundary

The July 2026 comparison found adjacent Obsidian tools:

- Auto Classifier classifies tags from note text and frontmatter.
- Note Companion and Inbox Curator format and sort inbox notes.
- Auto Keyword Linker previews keyword-based links.
- Synapse is the closest match: it proposes AI enrichment, organization, and
  links with review and checkpoints.

Keep this plugin focused on the remaining distinctive contract:

- Durable four-property state stored in each note.
- Full-read selective polishing with byte-preserved originals and one-way
  provenance links.
- Separate organization, archive, and semantic-link skills.
- User-only `complete` and per-action approvals.
- Exact executable Dry Runs with file-drift rejection.
- Cross-session resume from files instead of hidden agent memory.

Do not turn this Skill bundle into another Obsidian UI or model-provider plugin
unless the user later asks for an in-app product.
